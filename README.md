# 📝 Task Manager

A simple, lightweight, and interactive **Task Manager Web App** built with **HTML, CSS, and Vanilla JavaScript**. It helps users **add, edit, delete, filter, and track tasks** with persistent storage in the browser.  

---

## 🚀 Features
- ✅ Add, edit, and delete tasks  
- ✅ Mark tasks as completed or pending  
- ✅ Filter tasks (All | Pending | Completed)  
- ✅ Task statistics (Total | Completed | Pending)  
- ✅ LocalStorage support for persistence  
- ✅ Clear completed or all tasks with one click  
- ✅ Toast notifications for user feedback  
- ✅ Drag-and-drop to reorder tasks  
- ✅ Keyboard shortcuts:  
  - `Ctrl + Enter` → Add task  
  - `Esc` → Cancel editing

## ⚙️ Installation & Usage

1. Clone or download the repository.  
   ```bash
   git clone https://github.com/your-username/task-manager.git
   cd task-manager
   ```

2. Open `taskmanger.html` in any modern web browser.  
   - No server setup required  
   - Works offline
